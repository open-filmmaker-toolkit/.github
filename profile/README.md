## Open Filmmaker Toolkit

Free, open-source tools and templates for documentary and independent narrative filmmakers. Open a tool in your browser, load your project file, and keep working: your data never leaves your computer.

<p align="center">
  <img alt="One project file shared by the clearance log and the music cue sheet" src="https://raw.githubusercontent.com/open-filmmaker-toolkit/.github/main/profile/demo-preview.svg" width="860" />
</p>

> **Status:** Pre-launch. Our code is private while the licenses go through legal review, so there is nothing to browse here yet. This page will link to everything at launch.

### What's coming

| Tool | What it does |
| --- | --- |
| **Clearance log** | Track every piece of third-party material (footage, music, art in the frame) from request to licensed, and print a report for your E&O attorney. |
| **Music cue sheet** | Build a delivery-ready cue sheet, pulling music straight from the clearance log. |

Both tools are a single HTML file that runs offline and share one project file, so the work you do in one shows up in the other.

### Principles

- **Your data stays yours.** No accounts, no servers, no tracking, no network requests.
- **Nothing to install.** Open the file in a browser.
- **Plain, open formats.** One documented JSON project file, with a published schema.
- **Fictional samples only.** We never ship real people, contracts or footage.
